# Universal Software Product Design System (Brand Guideline)

> **Status:** Project-wide design guideline (Single Source of Truth)  
> **Location:** Modularized under .agent/rules/design/  
> **Master Index:** [.agent/rules/design/README.md](./rules/design/README.md)  
> **Design direction:** Warm retro developer workbench — tactile, structured, dense, calm, and functional  
> **Primary rule:** Personality belongs around the work. Clarity belongs inside the work.

---

## 🗂️ Modular Design System Modules

The full brand guideline has been modularized into structured topic files under .agent/rules/design/ for clear navigation and progressive disclosure:

1. **[README & Core Principles](./rules/design/README.md)**: Design philosophy, governing axioms, and modular index.
2. **[01. Design Tokens, Spacing & Surfaces](./rules/design/01-tokens-and-surfaces.md)**: Color palettes, warm neutrals, border tokens, spacing scale, and elevations.
3. **[02. Typography & Iconography](./rules/design/02-typography-and-icons.md)**: Technical font scale, monospace data numerals, and Lucide iconography rules.
4. **[03. Application Layout & Navigation](./rules/design/03-layout-and-navigation.md)**: Workbench shell, narrow desktop/mobile responsive grids, and page templates.
5. **[04. Component Guidelines & State System](./rules/design/04-components-and-states.md)**: 43 UI component specifications and full 10-state coverage (Default, Hover, Active, Disabled, Loading, Empty, Error...).
6. **[05. Financial Data Visualization](./rules/design/05-data-visualization.md)**: Financial charts, bar/line graphs, tooltips, axes, and color schemes.
7. **[06. Interactions & Workflows](./rules/design/06-interactions-and-behaviors.md)**: Search, filters, sort, resizable panels, bulk actions, and confirmation modals.
8. **[07. Motion, Accessibility & Implementation Contract](./rules/design/07-motion-accessibility-contract.md)**: Micro-interactions (100-240ms), WCAG 2.2 AA accessibility, and review checklists.

---

*All frontend engineers and UI subagents must strictly comply with these modules 100%.*

# App wireframe note v1

Mục tiêu: một màn hình giúp analyst trả lời nhanh một câu hỏi phân tích ngành.

```text
[Ngân hàng] [Kỳ] [Chỉ số] [Chạy phân tích]

[Trạng thái dữ liệu] [Ô hợp lệ] [Ô thiếu] [Evidence]

Tóm tắt
  - Điều đáng chú ý
  - Điểm cần kiểm tra

Bảng số liệu
  Ngân hàng | Kỳ | NPL | Coverage | ROA | ROE | Trạng thái

Khi chọn một ô:
  Giá trị → định nghĩa/kỳ tính → nguồn → trang → đoạn trích

Thiếu hoặc xung đột
Nguồn và chi tiết lần chạy
```

Không hiển thị thuật ngữ agent trong luồng chính. Chi tiết role, tool và trace chỉ nằm ở phần chi tiết lần chạy.
